# 具身研习室

具身智能世界模型中文论文资料库、学习路线与交互实验。

[打开学习站](https://zacharyzs.github.io/world-model-lab/) · [进入论文资料库](https://zacharyzs.github.io/world-model-lab/#library) · [下载完整站点](https://github.com/zacharyZs/world-model-lab/releases/latest/download/world-model-lab.zip)

第一次学习可以从首页的学习路线开始，沿 23 篇重点材料逐步阅读。也可以在资料库中按论文查找中文研读、逐段译稿和配图。v7 收录三份推荐清单中的 49 项资料，其中 45 篇配有逐段译稿。

## 发布新版本

在 GitHub Releases 创建一个新版本，附上名为 `world-model-lab.zip` 的完整站点包。`index.html` 位于压缩包根目录。发布版本后，打开 [Publish study site](https://github.com/zacharyZs/world-model-lab/actions/workflows/pages.yml)，点击 **Run workflow**，保留 `main` 分支，填写版本标签（例如 `v7`）并运行。部署成功后，同一学习网址会展示所选版本。
